## 논문이 보여주는 것

Smallville은 건물 내부를 별도 화면 뒤에 숨기는 대신, 항상 보이는 지붕 없는
돌하우스 뷰를 사용한다. Figure 2는 한 가족 주택을 다음과 같은 시맨틱 영역으로
표시한다:

- 욕실
- 주방
- 공용 공간
- 침실
- 정원

공용 공간은 책장과 테이블 같은 오브젝트로 더 구체화되어 있다. 논문은 모든
주요 생활 공간에 침대, 책상, 옷장, 선반, 욕실, 주방이 포함된다고 명시한다.

이는 단순한 시각적 선택이 아니다. 환경은 포함 관계 트리(`Town > Building >
Room > Object`)로 표현되며, 에이전트의 자연어 행동은 리프(leaf) 오브젝트로
해석된 뒤 일반적인 게임 경로탐색을 통해 아바타를 그곳으로 이동시킨다.

## Agent Crossing 적용 방식

따라서 실외 맵 위의 주택은 다음을 만족해야 한다:

1. 불투명한 지붕 없이 렌더링할 것.
2. 침실, 공용 공간, 주방, 욕실의 경계를 항상 노출할 것.
3. 식별 가능한 침대, 책상, 선반, 테이블, 주방 조리대, 욕실 설비를 포함할 것.
4. 에이전트를 현재 계획/행동에 가장 잘 맞는 방에 배치할 것.
5. 실내 아바타 위에 현재 행동을 표시할 것.
6. 재사용 가능한 홈 템플릿에서 레이아웃을 도출해, 새 주택마다 별도의 씬 코드를
   작성하지 않아도 되게 할 것.

에이전트가 집에 있는지 여부는 여전히 백엔드가 소유한다. 프론트엔드는 그 상태를
실내 관측 위치로 투영할 뿐이며, 내비게이션을 임의로 만들거나 에이전트의 정식
타일을 변경해서는 안 된다.
