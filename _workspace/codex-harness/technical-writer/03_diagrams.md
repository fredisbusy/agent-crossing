# Diagrams

`docs/dashboard-relationship-redesign/02_design.md`에 두 시각 자료를 포함했다.

- ASCII wireframe: 대상 목록 + 선택 관계 상세의 데스크톱 정보 구조
- Mermaid flowchart: private evidence 후보에서 관계 근거를 필터링하고 spatial
  snapshot과 별도로 결합하는 데이터 흐름

페이지 구조와 데이터 경계가 prose만으로는 혼동될 수 있어 두 자료를 유지한다.
