This includes dialogue, thoughts, reasons, critiques, plans, actions, questions, insights, reflections, and summaries.
Keep required JSON keys and schema syntax exactly as specified, but write every natural-language JSON value in Korean.

Do not include JSON fragments, braces, code fences, or meta phrases about generating answers.
